# Резюме — Денис Воронков

Одностраничный сайт с резюме и портфолио: оформление, тексты, соцсети.
Чистый HTML, CSS и JavaScript без сборки и зависимостей.

**Адрес:** https://askuyr.github.io/resume/

Оформление: светло-серая бумага, крупная чёрная типографика Unbounded,
красный акцент. Резюме можно скачать прямо со страницы — в PDF и DOCX.

## Что внутри

| Раздел | Содержание |
|---|---|
| Hero | крупная обложка «Портфолио», веер карточек работ, кнопки «скачать резюме» и «написать» |
| 01 О себе | краткое описание, четыре факта |
| 02 Навыки | 8 карточек: стиль, соцсети, тексты, видео, нейросети, компьютеры, программы, обучаемость |
| 03 Проекты | 4 кейса: брендинг, программа форума, два сайта — со ссылками на проекты |
| 04 Опыт | 3 места работы и образование |
| 05 Что ещё могу | техподдержка, простые сайты, личные качества |
| 06 Рекомендации | два контакта с телефонами |
| 07 Контакты | телефон, почта, GitHub, резюме в PDF и DOCX |

Отдельная страница **branding.html** — брендинг «Нового поколения»:
знак в пяти вариантах, палитра с кодами, носители (флаг, футболки, папка, шоппер, значки).

## Файлы

```
index.html                 разметка
branding.html              страница брендинга
manifest.webmanifest       данные для установки на телефон
assets/css/style.css       стили
assets/js/main.js          меню, появление блоков, копирование почты
assets/fonts/*.woff2       Unbounded (400, 700)
assets/img/*.jpg|png       фото, обложки кейсов, иконки, OG-картинка
assets/img/brand/*         знак в 5 вариантах и носители
assets/docs/*.pdf|docx     резюме для скачивания
```

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки как на сервере:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт лежит в корне ветки `main` репозитория `askuyr/resume`.
GitHub Pages раздаёт его как project pages: https://askuyr.github.io/resume/.

```bash
git add .
git commit -m "site: резюме и портфолио"
git push origin main
```

## Принципы

- Никаких вымышленных проектов, метрик и технологий.
- Имена и контакты публикуются только с согласия людей: в кейсе юриста указано имя Кирилла Чигирина.
- Политическая символика в оформлении сайта не используется.
- Один запрос к сети — только за шрифтами и картинками самого сайта.
- Работает без JavaScript: текст и ссылки остаются доступными.
